# Earlier spatial observations

This passive evidence selection retains earlier Linux spatial cases, their software comparisons, and the remaining adjacent-value control observations. It provides historical records, not a build or execution target. Current cBPF controls and these earlier experimental source epochs remain separate.

- `cve/` contains the source-fidelity map, historical validation and containment records, matched capability/software controls, configurations and build receipts. Its [direct ring-buffer record](cve/ringbuf-direct-report.json) is report-only: the corresponding raw consoles were not located.
- `adjacent-store/` and `adjacent-load/` complete the raw control rows accompanying the separately retained [store](../spatial/adjacent-v5/experiment-result-v2.json) and [load](../spatial/adjacent-v6/experiment-result-v1.json) results. Their [correspondence](../spatial/README.md) remains conditional.
- `software-bounds/` retains the matched width-aware software comparison, including its earlier non-diagnostic integration failure as reported in the result record.

Files already present in the earlier spatial selection are not duplicated. Across both selections, all ten store-study and twenty load-study consoles are retained. These are two repetitions per condition; the native source epochs differ. The selected AEE-offset mechanism in the store study is not a faithful whole-system AEE implementation. The software configuration changes several mechanisms together, so it does not isolate one instruction or authority provenance as the sole cause.

The [publication manifest](../../publication-manifest.json) records original and public-copy identities. Source paths inside historical records refer to the earlier artifact structure; referenced code, images, runners and some transitive records are omitted. Personal paths and nonexperimental administrative bindings are redacted. Original hashes inside copies remain historical identities, not checksums for edited copies. The selection is not a portable experiment package, semantic revalidation or independent reproduction.

The original source-fidelity record distinguishes official reproducer instructions, selected public primitives with observation suffixes, and adapted consequences. These records support consequence-specific historical findings; they do not establish whole-CVE prevention, a current vulnerable-kernel replay, general verifier replacement, capability superiority over software bounds checks, temporal safety or native hardware performance.
